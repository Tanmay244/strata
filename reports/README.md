# Reports

Committed evidence for the grader. Each report states the tool, rule set and what was analyzed.

| Folder | Contents |
| --- | --- |
| `static-analysis/before/` | SpotBugs, PMD and AI-review output on `v1.0-iter1` code, before any fixes |
| `static-analysis/after/` | Same tools after fixes, no findings (W1 adds this) |
| `style/baseline/` | Checkstyle report for the iteration-1 code |
| `coverage/baseline/` | JaCoCo report for the iteration-1 code |
| `release/` | CI, style and coverage reports for the tagged iteration-2 release (W1 adds this) |
